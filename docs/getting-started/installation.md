# Installation

## Prerequisites

- **UniSim Design** installed and licensed on your machine.
- **Python 3.13.9 – 3.13.15** (tested; other versions may work but are untested).

## Python Dependencies

The framework relies on two external libraries. Install them via pip:

```bash
pip install pywin32 pandas
```

???+ info "Other libraries"
    `sqlite3` and `os` are part of Python's standard library — no separate install needed.
